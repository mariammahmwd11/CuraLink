## 🏥 CuraLink — Healthcare Management Platform

CuraLink is a full-stack healthcare management platform built with ASP.NET Core and .NET 10 to simplify healthcare workflows for patients, doctors, clinic receptionists, and administrators.

The platform supports appointment booking, online payments, prescription management, medical documents, real-time communication, notifications, and AI-assisted drug information.
